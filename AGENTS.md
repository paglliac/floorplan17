# Назначение

Проект превращает план и фотографии квартиры в интерактивный 3D-макет для сравнения расстановок. Оболочка просмотра и управление общие для разных квартир. Стены, проёмы, отделка и мебель относятся к конкретному объекту.

## План и фотографии

- Строй геометрию в метрах. Размеры бери с чертежа, отделку и порядок предметов сверяй по фотографиям. Привязывай разные ракурсы к окнам, дверям и углам, чтобы случайно не отзеркалить интерьер.
- Назначение комнат и бытовые сценарии уточняй по словам пользователя. Недостающие размеры можно оценить для макета. В результате кратко перечисли существенные допущения. Сведения об одной квартире храни с её моделью.

## Расстановки

- Представляй вариант как набор изменений к общей сцене. Просьбу «ещё вариант» выполняй отдельной расстановкой, сохраняя исходную для сравнения. При зеркальном переносе задай ось относительно плана и сохрани положение стен и проёмов.
- Переключатель меняет мебель и состояние выбранного варианта. Ракурс, центр обзора, масштаб и высота среза стен сохраняются. Камерой управляют жесты и отдельные кнопки вида.
- Проверяй, как комнатой пользуются: путь от двери, подход к кровати, открывание шкафов, раскладывание мебели, вид на экран с места посадки. У техники и мебели должны быть видимые опоры или крепления. Замечания воплощай в геометрии. Размерные линии, оценочные бейджи и разметку проблем добавляй только по запросу.

## Интерфейс

Пиши UI как рабочую ERP-систему. На экране оставляй то, по чему пользователь принимает решение. Используй стандартные компоненты проекта, таблицы, числа, статусы, цвет и подсказки в `title`. Подписи и заголовки — 1–3 слова. На странице один заголовок без поясняющего подзаголовка. Пустое состояние и предупреждение — одна строка. Методики расчёта и пояснения для разработчика оставляй в коде или документации.

## Запуск и проверка

Текущий просмотрщик — статическое приложение на Three.js. Точка входа — `index.html`, сборка не требуется. Для запуска из корня используй `python3 -m http.server 8174 --bind 127.0.0.1`. После правки осмотри результат сверху и под углом. Выбери свой ракурс, приблизь модель и переключи затронутые варианты: мебель должна меняться в том же кадре.

## Файлы и буфер обмена

Документы, тексты и промпты сохраняй локально и давай полный путь. Не используй Artifact, Codex Docs и другие внешние страницы для артефактов. В буфер обмена пиши только по прямой просьбе пользователя.
